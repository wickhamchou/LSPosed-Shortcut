# LSPosed-Shortcut

A solution when LSPosed cannot add shortcuts.

Support most versions

Tested on LSPosed 1.9.2, 1.9.2-ir, 2.0.4, 2.1.1

**HOW TO USE**

For Magisk user, root authorization is required;

For Apatch/KSU user, root privileges need to be granted manually.

Than just open it.

————————————————————————————————————————————————————

**How it works**

Run the action.sh file in LSPosed.zip. 

I'm simply packaging action.sh into an application.

————————————————————————————————————————————————————

当 LSPosed 无法添加快捷方式时，此方案可解决此问题。
